Chuleta básica

Comandos esenciales de Podman en macOS. Imprimir y pegar junto al terminal.

La machine (VM Linux)

podman machine initCrea la VM (solo una vez)
podman machine startArranca la VM
podman machine stopDetiene la VM
podman machine listVMs y su estado
podman infoDiagnóstico; busca host.ok: true

Contenedores

podman run -d --name X IMAGENLanza en segundo plano con nombre
podman run -p 8080:80 IMAGENPublica Mac:8080 → cont:80
podman run --rm IMAGEN cmdSe borra al terminar
podman ps / podman ps -aCorriendo / todos (incl. parados)
podman logs XSalida del contenedor
podman stop X / start XParar / reanudar
podman rm XBorra el contenedor
podman exec -it X shShell dentro del contenedor
podman inspect XJSON con todo su estado

Imágenes

podman pull IMAGENDescarga sin ejecutar
podman imagesImágenes locales
podman rmi IMAGENBorra una imagen
podman build -t NOMBRE .Compila un Containerfile

Montar código del host (clave para desarrollo)

-v $PWD:/appMonta el directorio actual en /app
-v $PWD:/app:roSolo lectura
-w /appDirectorio de trabajo dentro
--userns=keep-idMisma UID: evita líos de permisos rootless
Trampa: sin ./ ni / al inicio de la ruta fuente, Podman la interpreta como volumen con nombre, no como ruta (podman-run(1)).

Errores frecuentes

cannot connectLa machine está apagada → podman machine start
connection refused en localhostFalta -p o el proceso no escucha en 0.0.0.0
permission denied en -vAñade --userns=keep-id
port already in useCambia el puerto izquierdo de -p

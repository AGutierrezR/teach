# Grep Resources

## Knowledge

- [GNU Grep Manual (official)](https://www.gnu.org/software/grep/manual/grep.html)
  The definitive reference: every option, regex dialect, and example with plain explanations. Use for: any claim about grep behavior, exit codes, and flag references.
- [grep(1) man page — man7.org](https://man7.org/linux/man-pages/man1/grep.1.html)
  Local-first reference. On macOS, plain `man grep` covers it. Use for: quick syntax and flag lookups while practicing.
- [ripgrep Guide — Andrew Gallant (BurntSushi)](https://github.com/BurntSushi/ripgrep/blob/master/GUIDE.md)
  The author's own guide to rg, the modern code-search tool. Use for: the alternative to grep, when to switch, and its defaults (gitignore-aware, skips binaries).
- [ripgrep vs grep benchmarks (ripgrep.dev)](https://ripgrep.dev/benchmarks)
  Independent benchmark data on the speed gap. Use for: deciding grep vs rg on big repos.
- [The Art of the Command Line — Joshua Levy & others](https://github.com/jlevy/the-art-of-command-line)
  Free, venerable, high-trust collection of terminal skills. One-page grep cheatsheet section. Use for: core verb-sword mental model around pipes.

## Wisdom (Communities)

- [r/commandline](https://www.reddit.com/r/commandline/)
  High-signal subreddit for terminal tips; good for real-world grep/rg tricks.
- [Unix & Linux Stack Exchange](https://unix.stackexchange.com/)
  Canonical answer-base for "why does grep do X" questions. Search before posting.

Captura de nodos (roam)

Plantillas de la extensión roam: crean nodos, no texto. Comando: Space O m c (roam_capture). Directorio de nodos: ~/org/roam.

Estructura en opts.extensions

roam = { directory = "~/org/roam", capture_templates = { KEY = { description = "…", -- etiqueta del menú template = "%?\n", -- cuerpo del nodo target = "%<%Y%m%d%H%M%S>-${slug}.org", -- nombre de archivo head = "#+title: ${title}\n", -- cabecera del nodo nuevo }, }, },

Campos

CampoQué hace
descriptionEtiqueta en el menú.
templateCuerpo del nodo. %? = cursor.
headTexto escrito en el archivo nuevo (típ. #+title:).
targetDónde va: archivo nuevo o una forma (tabla abajo).
typeComo org-capture: plain (def.), entry…
propertiesPropiedades del nodo/entry.
unnarrowedEditar el texto ya en el archivo destino.

Escapes del nodo (${…})

EscapeInserta
${title}El título del nodo.
${slug}Título en minúsculas, _ por lo no alfanumérico.
${id}El UUID del nodo.
${file}La ruta del nodo.
${clave}Cualquier otra: se pregunta una vez.
${clave=def}Se pregunta, con ese valor por defecto.

Los escapes %… de org-capture (%?, %u, %a, %^{…}) también funcionan aquí.

Formas de target

FormaResultado
"…-${slug}.org"Nodo nuevo (archivo propio).
{ "file", path }Bajo el archivo path.
{ "file+head", path, head }Archivo nuevo con cabecera head.
{ "file+olp", path, { "A","B" } }Bajo cabeceras que ya existen.
{ "file+head+olp", … }Cabecera + ruta de outline.
{ "file+datetree", path, tree }Árbol de fechas (day/week/month).
{ "node", "Título" }Capturar dentro de un nodo existente.

Plantilla por defecto de roam

d = { description = "default", type = "plain", template = "%?", target = "%<%Y%m%d%H%M%S>-${slug}.org", head = "#+title: ${title}\n", unnarrowed = true, },

La plantilla “default” de fábrica

La extensión roam trae siempre una plantilla d (descripción “default”). org.nvim fusiona diccionarios en profundidad, así que tus plantillas se añaden a esta, no la reemplazan:

d = { description = "default", type = "plain", template = "%?", target = "%<%Y%m%d%H%M%S>-${slug}.org", head = "#+title: ${title}\n", unnarrowed = true, }

No se puede borrar desde la config; solo redefinir usando la misma clave d. (Las dailies tienen su propia d: entry, * %?, %<%Y-%m-%d>.org.)

Tu configuración (idea + MOC + literatura)

roam = { directory = "~/org/roam", capture_templates = { i = { description = "Idea (nodo)", template = "%?\n", target = "%<%Y%m%d%H%M%S>-${slug}.org", head = "#+title: ${title}\n", }, m = { description = "MOC (nodo)", template = "Mi mapa de ${title}. Empezar aquí.\n%?\n* \n* \n", target = "%<%Y%m%d%H%M%S>-moc-${slug}.org", head = "#+title: MOC ${title}\n#+filetags: moc\n", }, l = { description = "Literatura (nodo)", template = "%?\n %a", target = "%<%Y%m%d%H%M%S>-${slug}.org", head = "#+title: ${title}\n#+filetags: literature\n", }, }, },
MOC en un paso

La plantilla m crea el nodo ya titulado MOC …, con #+filetags: moc y el esqueleto de intro + grupos. Cumple la regla de la lección 03: título, tag e intro listos para enlazar.

Efímera o nodo

Ya es permanente (idea, fuente) → Space O m c (nodo). Aún no lo sé / del día → Space O c (efímera al inbox). Relacionado: Space O m f crea un nodo y lo visita.

Aparte: captura de fuentes web

capture_ref_templates alimenta el protocolo roam-ref: capturas una web y el nodo nace con ROAM_REFS: URL. Requiere configurar el protocolo en el navegador; se verá más adelante.

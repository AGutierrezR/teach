Plantillas de captura

Config de capture.templates en org.nvim. Abrir menú: Space O c. Finalizar: C-c C-c. Abortar: C-c C-k.

Estructura en opts

capture = { templates = { KEY = { description = "…", -- etiqueta del menú template = "* %?\n %u", -- esqueleto target = "~/org/refile.org", -- destino ("", = default_notes_file) headline = "Inbox", -- cabecera destino (se crea si falta) }, }, },

Campos de una plantilla

CampoQué hace
descriptionEtiqueta en el menú de captura.
templateTexto; con * es un entry. Sin * se añade uno.
typeentry, item, checkitem, table-line, plain.
targetArchivo, "" (default), clock, o función.
headlinefile+headline: cuelga bajo esa cabecera.
olpfile+olp: ruta de cabeceras que deben existir.
datetreeÁrbol de fechas (true o { tree_type = "week" }).
propertiesPropiedades añadidas al entry.
immediate_finishFinaliza sin abrir la ventana de captura.
unnarrowedEditar el texto directamente en el archivo destino.

Escapes del template

EscapeInserta
%?Posición del cursor.
%t / %TFecha activa / fecha y hora.
%u / %UFecha inactiva / fecha y hora.
%<fmt>strftime, p. ej. %<%Y-%m-%d>.
%aEnlace (anotación) al origen de la captura.
%iContenido inicial (la selección en Visual).
%xPortapapeles.
%^{Texto}Pregunta ese texto.
%^{Texto|a|b}Pregunta con opciones a/b.
%^{PROP}pPregunta y guarda como propiedad PROP.
%\\1La respuesta al 1.er prompt %^{…}.

Tus tres plantillas

capture = { templates = { n = { description = "Nota (a procesar)", template = "* %?\n %u\n %a", target = "~/org/refile.org", headline = "Inbox" }, t = { description = "Tarea", template = "* TODO %?\n %u\n %a", target = "~/org/refile.org", headline = "Tasks" }, r = { description = "Referencia", template = "* %^{Título}\n %u\n %a\n %^{URL}", target = "~/org/refile.org", headline = "Inbox" }, }, },
Recordatorios

Tras editar opts hay que reiniciar Neovim. La clave (n/t/r) es lo que pulsas para elegir. La plantilla de referencia solo escribe la URL; ROAM_REFS/nodo es captura de roam (lección futura).

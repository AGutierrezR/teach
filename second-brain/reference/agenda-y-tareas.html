Agenda y tareas

Estados TODO, fechas (SCHEDULED / DEADLINE), vistas de agenda y refile. Prefijo: <leader>O (leader = Space).

Palabras clave (estados)

todo_keywords = { "TODO(t) NEXT(n) WAITING(w@) | DONE(d!) CANCELLED(c@)" } -- (k) tecla rápida · ! registra fecha · @ pide nota · | separa activos de hechos
AtajoAcción
S-Right / S-LeftCiclar al estado siguiente / anterior en la cabecera.
Space O SElegir un estado de una lista (todo_select).
C-c C-tEquivalente Emacs de Space O S.

Fechas

AtajoAcción
Space O sSCHEDULED: — cuándo planeas trabajarla.
Space O dDEADLINE: — cuándo vence (aviso 14 días antes).
Space O i .Timestamp activo <…>.
Space O i !Timestamp inactivo […].
S-Left / S-RightMover la fecha un día (sobre el timestamp).
S-Up / S-DownMover un minuto (timestamps con hora).

Repetidores: +1w (fijo), ++1w (desde hoy), .+1d (desde la última hecha). Retraso de un SCHEDULED: -2d. Aviso de DEADLINE: deadline_warning_days (14).

Registro (logging)

OpciónQué hace
log_done = "time"Añade CLOSED: al marcar DONE.
log_repeat = "time"Registro al completar una tarea repetida (por defecto).
log_reschedule / log_redeadlineRegistrar cambios de SCHEDULED / DEADLINE.

Refile

AtajoAcción
Space O rMover el subtree a un destino.
Space O RCopiar el subtree a un destino.
R (agenda)Refile la entrada bajo el cursor.
refile = { max_level = 3, -- cabeceras de los archivos de agenda hasta nivel 3 include_current_file = true, }

Sin esto, los destinos por defecto son las cabeceras del buffer actual. Con max_level, refile cruza todos tus archivos de agenda.

Comandos :Org

ComandoAcción

:Org agenda nAgenda + todos los TODOs.
:Org todo_listLista global de TODOs (opcional: un keyword).
:Org search <texto>Búsqueda en los archivos de agenda.
:Org tags_search <match>Match de tags / propiedades.

El bucle completo

Capturar → Space O c al inbox (rápido, sin decidir) Procesar → Space O S + Space O s estado + fecha Refile → Space O r a su proyecto Trabajar → Space O a n desde la agenda
Regla de oro

¿Dudas de una tecla en la agenda? g?. ¿Dudas en un buffer org? g?. La lista se filtra con /.

Captura de nodos (roam_capture)

Tu captura actual deja una nota efímera en el inbox. Roam tiene su propio sistema de plantillas que crea el nodo directamente: un archivo con #+title e :ID:, sin pasar por el procesado.

00Antes de empezar: recuerda

¿Qué decide el campo target?
El target (más el headline) es el destino: archivo y cabecera.
¿Qué inserta el escape %u?
%u es fecha inactiva (entre corchetes); %t es la activa (con ángulos).

01Dos sistemas de captura

Ya conoces el primero. El segundo es el de la extensión roam, y su unidad no es una línea, sino un nodo.

Global (capture.templates)Roam (roam.capture_templates)
Qué produceTexto en un destinoUn nodo (archivo con #+title e :ID:)
UnidadNota efímeraNota permanente
Escapes propios—${title}, ${slug}, ${id}
AtajoSpace O cSpace O m c
Regla de decisión

¿Ya sé que es permanente? (una idea, una fuente) → captura de nodo (Space O m c). ¿Aún no lo sé, o es algo del día? → captura efímera al inbox (Space O c).

02Anatomía de una plantilla de nodo

Se parecen a las que ya usas, con dos añadidos: head (lo que se escribe en la cabecera del archivo nuevo) y escapes con ${…} que salen del nodo.

Campo / escapeQué es
target = "…-${slug}.org"Genera el nombre de archivo del nodo.
head = "#+title: ${title}\n"Escribe la cabecera del archivo nuevo.
${title}El título que escribas al crear el nodo.
${slug}El título en minúsculas, con _ en vez de lo que no sea letra/número.
${id}El ID (UUID) del nodo.
${pregunta=def}Cualquier otro ${…} te lo pregunta una vez.

El destino no tiene por qué ser un archivo nuevo. Estas son las formas de target de roam:

FormaPara qué
"…-${slug}.org"Un nodo nuevo (archivo propio).
{ "file+head", path, head }Archivo nuevo con una cabecera concreta.
{ "file+olp", path, { "A", "B" } }Bajo cabeceras que ya existen.
{ "node", "Título" }Capturar dentro de un nodo existente.
{ "file+datetree", path, "day" }Bajo un árbol de fechas.

03Tu configuración

Hoy tienes roam = true. Cámbialo por una tabla, manteniendo el directorio donde ya viven tus nodos (~/org/roam):

roam = { directory = "~/org/roam", capture_templates = { i = { description = "Idea (nodo)", template = "%?\n", target = "%<%Y%m%d%H%M%S>-${slug}.org", head = "#+title: ${title}\n", }, m = { description = "MOC (nodo)", template = "Mi mapa de ${title}. Empezar aquí.\n%?\n* \n* \n", target = "%<%Y%m%d%H%M%S>-moc-${slug}.org", head = "#+title: MOC ${title}\n#+filetags: moc\n", }, }, },

Con esto, Space O m c te ofrece Idea (nodo) y MOC (nodo). Escribes el título, el cuerpo, y al finalizar nace un archivo nuevo en ~/org/roam con su #+title y su :ID:.

La plantilla de MOC

Fíjate en dos detalles: el head escribe #+title: MOC ${title} (así el nodo se llama "MOC …") y añade #+filetags: moc; y el cuerpo nace con la intro y dos grupos vacíos, listos para enlazar notas. Con esta plantilla, crear un MOC (lección 03) es una sola captura.

Añadir más plantillas

Duplica el patrón para lo que necesites. Para fuentes, una clave l con tag propio en el head: head = "#+title: ${title}\n#+filetags: literature\n".

Verás una opción “default”

No es un error: la extensión trae una plantilla d de fábrica y org.nvim fusiona las plantillas en vez de reemplazarlas, así que d convive con las tuyas. Solo se redefine (misma clave d); no se borra. Detalle en la referencia.

04Aplícalo

  1. En org.lua, sustituye roam = true por el bloque de arriba.
  2. Guarda y reinicia Neovim.
  3. Pulsa Space O m c, elige Idea (nodo) y escribe un título (p. ej. Prueba de captura de nodo).
  4. Escribe una frase en el cuerpo y finaliza con C-c C-c.
  5. Abre el archivo nuevo: confirma que tiene #+title: y un :ID:.
  6. Desde otro nodo, enlázalo con Space O m i y comprueba el backlink.

05Compruébalo (recuperación)

¿Qué crea una plantilla de roam?
Un nodo: archivo con #+title e :ID:, listo para enlazarse.
¿Cuándo usas la captura de nodos?
Si ya sabes que es una idea o fuente con futuro, créala como nodo; si no, captura efímera al inbox.
¿Qué escape sale del nodo?
${title}, ${slug}, ${id} los provee el nodo; los %… siguen siendo los de org-capture.

06Práctica

  • Cambia roam = true por la tabla con capture_templates.
  • Reinicia Neovim y confirma que Space O m c ofrece Idea (nodo) y MOC (nodo).
  • Crea un nodo real y verifica #+title e :ID: en el archivo.
  • Crea un MOC con la plantilla m y enlázale 2-3 notas.
  • Añade otra plantilla (l, literatura) con el tag literature.
  • Enlaza el nodo nuevo desde otro con Space O m i y mira el backlink.
  • Usa la captura de nodo para algo real esta semana (una idea que ya sabes que es permanente).

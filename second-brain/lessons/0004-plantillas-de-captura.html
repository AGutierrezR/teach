Lección 04 · Herramientas

Plantillas de captura

Hoy Space O c siempre te crea un TODO. Vas a darle un menú: una plantilla para notas, otra para tareas, otra para referencias — y todas caen en tu inbox canónico.

00Antes de empezar: recuerda

¿Qué convierte una lista en un mapa?
Un MOC es un mapa porque comentas por qué las notas van juntas, no solo porque las enlazas.
¿Qué se decide al capturar?
La captura es rápida y sin decisiones; clasificar es cosa del procesado.

01Por qué tu captura solo hace tareas

En org.nvim, si no defines plantillas, se usa una por defecto: un TODO bajo la cabecera Tasks de tu default_notes_file (refile.org). Por eso cualquier cosa que capturas nace como tarea, quieras o no.

Una plantilla de captura es un formulario reutilizable que decide tres cosas: qué esqueleto de texto se inserta, a qué destino va, y con qué descripción aparece en el menú. Con varias plantillas, Space O c abre un menú en vez de asumir "tarea".

02Anatomía de una plantilla

CampoQué es
descriptionLa etiqueta que verás en el menú de Space O c.
templateEl esqueleto de texto. Un * inicial lo hace un entry.
targetArchivo destino. "" = tu default_notes_file.
headlineCuélgalo bajo esa cabecera; se crea si no existe.
olpRuta de cabeceras (deben existir) en vez de headline.
datetreeCuélgalo bajo un árbol de fechas (útil para dailies).

Y estos son los escapes que más vas a usar dentro del template:

EscapeInserta
%?Dónde queda el cursor al abrir.
%u / %UFecha inactiva / fecha y hora.
%t / %TFecha activa / fecha y hora.
%aEnlace al sitio desde donde capturaste.
%^{Texto}Pregunta ese texto al vuelo.
%^{PROP}pPregunta el valor y lo guarda como propiedad.

03Tu configuración: tres plantillas

Decisión (de la lección 02): tu inbox canónico es refile.org. Las notas y referencias van bajo una cabecera Inbox; las tareas bajo Tasks. Añade este bloque dentro de opts, al mismo nivel que extensions:

capture = { templates = { n = { description = "Nota (a procesar)", template = "* %?\n %u\n %a", target = "~/org/refile.org", headline = "Inbox", }, t = { description = "Tarea", template = "* TODO %?\n %u\n %a", target = "~/org/refile.org", headline = "Tasks", }, r = { description = "Referencia", template = "* %^{Título}\n %u\n %a\n %^{URL}", target = "~/org/refile.org", headline = "Inbox", }, }, },
Cómo leer esto

La clave (n, t, r) es lo que pulsas para elegir la plantilla. %? deja el cursor listo para escribir. %u pone la fecha de captura. %a guarda el enlace a donde estabas. En la de referencia, %^{Título} y %^{URL} te preguntan esos dos datos.

Un detalle de la plantilla de tarea: ese TODO es una palabra clave (keyword) de org. No es texto decorativo: marca la cabecera con un estado (TODO, DONE…) y es lo que convierte una línea en una tarea de verdad. Aquí basta con reconocerlo; lo usaremos a fondo en la lección 06.

Un límite honesto

La plantilla de referencia solo escribe la URL en la nota; no la convierte en ROAM_REFS ni crea un nodo. Eso es la captura de roam (vía roam_capture), que es tema de una lección futura. Aquí basta con no perder la fuente.

04Aplícalo

  1. Abre tu config: ~/.config/nvim/lua/plugins/org.lua.
  2. Pega el bloque capture = { … } dentro de opts, hermano de extensions.
  3. Guarda (:w) y reinicia Neovim (los opts no se recargan en caliente).
  4. Pulsa Space O c: ahora aparece un menú con Nota, Tarea y Referencia.
  5. Prueba la de Nota: escribe algo, finaliza con C-c C-c y comprueba que aparece bajo * Inbox en refile.org.

05Compruébalo (recuperación)

¿Qué es una plantilla de captura?
Esqueleto + destino + etiqueta: lo que convierte la captura en algo repetible.
¿Qué hace %? en la plantilla?
%? es la posición del cursor; para preguntar un dato se usa %^{…}.
¿En qué se convierte el destino?
El target (y su headline) deciden el archivo y la cabecera donde aterriza.

06Práctica

  • Añade el bloque capture con las tres plantillas a org.lua.
  • Reinicia Neovim y confirma que Space O c muestra el menú.
  • Captura una Nota real y verifica que cae bajo * Inbox.
  • Captura una Tarea y verifica que cae bajo * Tasks.
  • Captura una Referencia y responde a los prompts de Título y URL.
  • Abre refile.org y comprueba que las tres se ven bien formadas.

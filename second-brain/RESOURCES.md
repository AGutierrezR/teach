# Second Brain (org-mode / org-roam) Resources

## Knowledge

- [Manual: org.nvim — extensión org-roam](https://org-nvim.com/manual/org-extensions-roam.html)
  La especificación de la herramienta que usa Andrés. Fuente de verdad para nodos, `:ID:`, `id:` links, backlinks, dailies, capturas. Usar para: cómo funciona org-roam *dentro de org.nvim*.
- [Manual: Org mode (orgmode.org)](https://orgmode.org/manual/)
  El estándar de texto plano que org.nvim reimplementa. Usar para: sintaxis org, keywords, drawers, agenda, capture, refile. Agnóstico del editor.
- [Manual: Org-roam (orgroam.com)](https://www.orgroam.com/manual.html)
  El modelo conceptual original (Emacs). Usar para: qué es un nodo, backlinks vs reflinks, el método detrás de la herramienta. Ojo: detalles de UI son de Emacs, no aplican a Neovim.
- [Manual: org.nvim — Captura](https://org-nvim.com/manual/org-capture.html) y [Refile](https://org-nvim.com/manual/org-refile.html)
  Usar para: construir el flujo *capturar → procesar*. Templates, targets, `%`-escapes.
- [Manual: org.nvim — Skill keys / Keymaps](https://org-nvim.com/manual/org-keymaps.html)
  Usar para: descubrir atajos. Recordatorio: `g?` muestra todos los atajos en cualquier buffer org.
- [Libro: _How to Take Smart Notes_ — Sönke Ahrens](https://takesmartnotes.com/)
  La metodología Zettelkasten aplicada a trabajo intelectual. Usar para: por qué las notas permanentes y los enlaces superan a las carpetas. (El resumen del método también está en el manual de org-roam.)
- [Libro: _Building a Second Brain_ — Tiago Forte](https://www.buildingasecondbrain.com/)
  El método PARA (Projects, Areas, Resources, Archive) + CODE. Usar para: organizar el lado accionable (proyectos/tareas), que es distinto de las notas de conocimiento. Origen del esqueleto que Andrés ya escribió.
- [Tutorial: org.nvim — the tour](https://org-nvim.com/examples/tutorial.html) y [feature examples](https://org-nvim.com/examples/00-index.html)
  Ejemplos ejecutables de cada función. Usar para: practicar una función concreta tras la lección.

## Wisdom (Communities)

- [r/orgmode](https://www.reddit.com/r/orgmode/)
  Subreddit activo. Usar para: dudas de configuración de forma de trabajo, ver setups de otros, pedir crítica al sistema.
- [Org-mode mailing list](https://orgmode.org/worg/org-mailing-list.html)
  La lista oficial, muy alto nivel técnico. Usar para: comportamiento del estándar org, bugs, preguntas profundas.
- [Org-roam Discourse](https://org-roam.discourse.group/)
  Foro del proyecto org-roam. Usar para: metodología de caja de notas, dudas de workflow (no de org.nvim específicamente).
- GitHub org.nvim — [Issues](https://github.com/xheisenbugx/org.nvim/issues)
  Usar para: reportar diferencias con el manual, pedir features. El autor responde.

## Gaps

- No hay todavía una fuente de alta confianza específica sobre *workflows de org-roam en Neovim* (todo está orientado a Emacs). Se cubrirá con lecciones propias y práctica, citando los manuales como base.
